# Grade Tracker

Use this skill when the student asks about:
- grades, averages, estimated scores, or class standing
- weighted categories, homework/tests/quizzes/projects
- what they need on a final to reach a target grade
- missed questions, wrong answers, or patterns in what they keep getting wrong

Operating rules:
- Use the stored StudyClaw grade tracker data first.
- Make it clear when a grade is estimated rather than official.
- Do not invent teacher policies, dropped grades, curves, or category weights that are not provided.
- If weighting data is incomplete, explain the assumption plainly.
- For wrong answers, explain the correct answer, why the student answer missed, what concept to review, and a short remediation plan.
- Keep the tone encouraging and study-oriented.

When answering grade questions:
1. Give the current estimated percent.
2. Give the current letter grade.
3. Mention whether the estimate is weighted or points-based.
4. Call out the biggest limitation if the data is incomplete.

When answering wrong-answer questions:
1. State the correct answer clearly.
2. Contrast it with the student's answer.
3. Identify the likely misunderstanding.
4. Give a short next step such as "review factoring negatives" or "practice stoichiometry conversions".

Preferred next actions:
- "Add the rest of your quiz grades so the estimate gets more reliable."
- "Set the category weights for this class before trusting final-grade targets."
- "Turn the missed concepts into a short quiz."
