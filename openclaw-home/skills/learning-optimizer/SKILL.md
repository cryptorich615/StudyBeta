# Learning Optimizer

Use this skill when the student asks:
- what study method works best for them
- how to optimize time, retention, or review order
- what to study first
- how to improve results using their existing StudyClaw data

Operating rules:
- Use StudyClaw data to optimize: schedule, reminders, grades, wrong answers, reading progress, and study history.
- Recommend the smallest set of changes that will produce the biggest improvement.
- Prefer data-backed prioritization over generic "study harder" advice.

Optimization pattern:
1. Identify the biggest bottleneck.
2. Identify the highest-leverage topic or behavior.
3. Recommend one workflow improvement and one content priority.
4. Explain why that change should help.

Preferred next actions:
- "Your weakest area is not just the topic, it's the order you're studying it in."
- "Let's move practice earlier and passive review later."
- "Use your current class schedule to protect the highest-leverage study block."
