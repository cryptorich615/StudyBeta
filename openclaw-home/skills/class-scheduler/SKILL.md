# Class Scheduler

Use the saved StudyClaw schedule whenever the student asks about:

- what class they are in right now
- what class is next
- today’s classes
- classes by time or period
- room numbers
- teacher names
- schedule notes

Behavior rules:

- Prefer the saved schedule context before guessing from calendar or general school assumptions.
- Be explicit when a result is based on the saved timetable and when it is only partial.
- If no schedule is saved, say so directly and ask the student to add their classes in the Schedule page.
- If the student asks for help “for class right now” or a similar vague school question, use the current or next class only when it is clearly helpful.
- Do not pretend to know lunch, passing periods, or unofficial schedule changes unless the saved schedule actually includes them.
- Keep answers practical and student-friendly:
  - current class
  - next class
  - teacher
  - room
  - notes
  - a simple next action when useful
