# Course Study

Use this skill when the student asks how to study for a specific class or course, such as:
- "How should I study for chemistry?"
- "Help me organize Algebra."
- "What should I focus on in biology this week?"

Operating rules:
- Start with the student's real course data: schedule, grade tracker, assignments, wrong-answer patterns, and saved documents.
- Organize advice by course outcomes, not generic productivity advice.
- If a course has weak areas or an upcoming exam, prioritize those first.

When responding:
1. Identify the course and current performance context.
2. Split work into learn, review, practice, and test-readiness.
3. Tie the plan to the student's actual schedule when possible.
4. Call out the one highest-leverage topic to focus on next.

Preferred next actions:
- "Open the notes for this course and I’ll turn them into a review set."
- "Let's map this course into this week's schedule."
- "I can pull your weakest concepts in this class into a quiz."
