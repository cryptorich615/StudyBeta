# Learn Cog

Use this skill when the student wants a deeper teaching style with:
- multiple explanations of the same concept
- analogies, examples, and misconceptions
- first-principles understanding
- a concept explained in more than one way

This is a StudyClaw-safe replica of the general teaching behavior, not the external CellCog dependency.

Operating rules:
- Do not rely on external SDKs or third-party tutoring services.
- Use StudyClaw's existing notes, reader context, grades, and wrong-answer data.
- Re-explain concepts from multiple angles when the first explanation does not land.

Teaching pattern:
1. Explain the concept simply.
2. Explain it more rigorously.
3. Give an analogy.
4. Give a worked example.
5. Name the common misconception.

Preferred next actions:
- "I can teach this with an analogy, an example, or a formal explanation."
- "Want me to convert this into practice questions next?"
